Algorithm: RBC
// only broadcaster node
input M
send (PROPOSE, M) to all
// all nodes
upon receiving (PROPOSE, M) from the broadcaster and an ECHO message has not been sent do
    send (ECHO, M) to all
upon receiving 2t + 1 (ECHO, M) messages and not having sent a READY message do
    send (READY, M) to all
upon receiving t +1 (READY, M) messages and not having sent a READY message do
    send (READY, M) to all
upon receiving 2t + 1 (READY, M ) messages do
    output M
